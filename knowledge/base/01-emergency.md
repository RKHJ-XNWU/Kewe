# 紧急与保命协议

## 这不是救援服务

网站不能代替警察、急救中心、消防或医生。它的价值是让你在最慌的时候少找一步：
把号码、位置、个人应急资料和联系人放在同一个页面。

## 危险发生时的最短路径

1. 先离开正在发生的危险源，到有人的、亮的地方。
2. 拨打：
   - 110：违法犯罪、失踪、被威胁、被跟踪。
   - 120：受伤、胸痛、呼吸困难、意识异常、严重过敏。
   - 119：火灾、被困、危险品泄漏、需要救援。
3. 说清楚：位置（城市/区/街道/门牌/附近地标）、发生了什么、有几个人、有没有人受伤。
4. 如果无法说话，尝试短信报警 12110（按所在地规则），或让身边人代为拨打。
5. 在安全位置等待，不要返回危险现场。

## 网站里的工具

- SOS 大按钮显示 110 / 120 / 119 一键拨号。
- 紧急联系人卡片调用 `tel:` 链接。
- 定位按钮只在用户点击并授权后读取经纬度，用于复制/分享。
- 医疗卡保存在浏览器本地，登录后可同步为账号知识条目，供模型参考。
- 所有页面在离线时仍可打开已加载的静态壳；号码和本地资料不依赖网络。

## 模型回答约束

- 不给医学诊断、不给危险自救动作、不保证结果。
- 用户处于即时危险时，先让其联系紧急服务和身边的人，再讨论其他。
- 若用户表达自伤/伤人意图，鼓励联系当地紧急服务与可信任的人，不提供方法细节。
- 不把“网站会救你”写成事实；只能说“这些工具帮助你更快求助”。
